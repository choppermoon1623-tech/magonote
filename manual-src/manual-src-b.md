## ふりがな付け
**ひとこと:** おたよりやプリントの文章を貼り付けると、学年に合わせて漢字にふりがなを自動で振り、印刷やコピーができます。
**使い方:**
1. 画面を開くと「辞書を読み込んでいます…」と表示されます。読み込みが終わるまで少し待ちます（初回のみ約17MB、2回目からはすぐ開きます）
2. 「📄 文章」の欄に文章を貼り付けます。お試しには「例文を入れる」ボタンが使えます
3. 「⚙️ ふりがなの付け方」で学年を選びます。「すべての漢字に付ける（総ルビ）」〜「小6までに習う漢字には付けない」から選択できます（初期設定は「小2までに習う漢字には付けない」）
4. 右側の白い紙面に、ふりがな付きの仕上がりが自動で表示されます
5. 読みが違う漢字は、プレビュー上でその漢字をクリックすると、その場で読みを入力し直せます（直した読みは緑色で表示。空にするとふりがな無し、「×」を入力すると元に戻ります）
6. 「🖨️ 印刷」で印刷するか、「📋 コピー（Word等へ）」でルビ付きのまま貼り付けられる形式でコピーします
**便利機能:**
- 「📖 読みの登録」欄に「漢字＝よみ」の形で1行ずつ書くと、子どもの名前など特殊な読みを優先して付けられます（例: 結愛＝ゆあ）
- 「同じ言葉は最初の1回だけ付ける」にチェックすると、繰り返し出る言葉のふりがなを1回目だけにできます
- 「縦書き」「明朝体」のチェックで、紙面の見た目を切り替えられます（印刷にも反映されます）
- 「📋 括弧書きでコピー」を使うと「漢字（かんじ）」の形式でコピーでき、ルビ非対応のソフトにも貼り付けられます
- 入力した文章・設定は自動保存され、次に開いたときに復元されます
**注意・コツ:**
- 文章は端末の外に送信されません
- 「コピー（Word等へ）」で貼り付け先がルビに対応していない場合は、「括弧書きでコピー」を使ってください
- 学年別の判定は2020年度からの学年別漢字配当表（1026字）に基づいています

## 画像形式変換
**ひとこと:** iPhoneのHEIC写真などを、JPEG・PNG・WebPにまとめて変換できます。
**使い方:**
1. 「ここに画像をドラッグ＆ドロップ」の枠に画像を入れるか、枠をクリックして選択します（複数枚OK。HEIC・HEIF・JPEG・PNG・WebP・GIF・BMP・AVIFに対応）
2. 「変換先」で「JPEG」「PNG」「WebP」のどれかを選びます（初期設定はJPEG）
3. 必要に応じて「画質」のスライダーを調整します（初期値88。下げるほど軽くなります・85前後が目安）
4. 「長辺の上限」で「元のまま」「2000px」「1600px」「1200px」「800px」から選ぶと、大きい写真を縮小して軽くできます
5. 「変換する」ボタンを押します。一覧に「変換中…」→変換後のサイズが表示されます
6. 各画像の「⬇ 保存」で1枚ずつ保存するか、「ZIPでまとめて保存」で全部を1つのZIPファイルで保存します
**便利機能:**
- 変換後は「元のサイズ → 変換後のサイズ（−何%）」が表示されるので、どれだけ軽くなったか一目でわかります
- 一覧の「✕」ボタンで、その画像だけ外せます。「すべてクリア」で全部やり直せます
- ZIP保存時、同じ名前のファイルは自動で連番が付き、上書きされません
- 変換先の説明が画面に表示されます（JPEG=写真向き、PNG=透過を保てる・図やスクショ向き、WebP=いちばん軽い）
**注意・コツ:**
- 変換はすべて端末の中で行われ、画像はどこにも送信されません。位置情報などのExifも変換時に消えます
- ブラウザがWebPの書き出しに対応していない場合、WebPボタンは押せなくなります
- JPEGは透過を保てないため、透過部分は白地になります。透過を残したいときはPNGを選んでください

## 写真リサイザー
**ひとこと:** たくさんの写真をまとめて縮小・軽量化し、ZIPで一括保存できます。
**使い方:**
1. 「画像をここへドロップ」の枠に写真を入れるか、クリックして複数選択します
2. 「最大幅」「最大高さ」を数字で指定します（初期値はどちらも1600）
3. 「出力形式」で「JPEG」「PNG」「WebP」から選びます
4. 「画質」のスライダーを調整します（初期値82%）
5. 「一括変換」ボタンを押します
6. 「プレビュー」で仕上がりを確認し、「ZIPで保存」でまとめて保存します
**便利機能:**
- 「選択」「元サイズ」「変換後」の表示で、枚数と容量の変化がひと目で確認できます
- 「小さい画像は拡大しない」チェック（初期オン）で、もともと小さい画像が引き伸ばされて画質が落ちるのを防げます
- 画面右上の「↺」（リセット）ボタンで最初からやり直せます
**注意・コツ:**
- 端末内で処理するローカルツールです。写真はどこにも送信されません
- 幅・高さは「上限」の指定です。縦横比は保たれたまま、指定サイズに収まるよう縮小されます

## 証明写真メーカー
**ひとこと:** スマホで撮った顔写真から、履歴書・パスポートなどのサイズの証明写真シートを作り、コンビニで印刷できます。
**使い方:**
1. 「顔写真をここにドロップ」の枠に写真を入れるか、「写真を選ぶ」ボタンで選びます（JPEG / PNG / WebP。無地の壁を背に正面から撮った写真がおすすめ）
2. 読み込むと顔が自動検出され、ガイド線に合う位置へ自動配置されます
3. 「サイズ」で用途を選びます。「履歴書・受験・英検（3×4cm）」「パスポート・マイナンバー（3.5×4.5cm）」「運転免許・国家試験（2.4×3cm）」「カスタム（mm指定）」から選べます
4. 「用紙」で「L判シート（コンビニ印刷用）」「A4シート」「1枚だけ（実寸データ）」を選びます
5. 左の写真をドラッグし、「ズーム」スライダーで大きさを調整します。頭のてっぺんとあごが緑の線の間に入るように調整してください
6. 右の「仕上がりプレビュー」を確認し、「💾 保存（JPEG・300dpi）」で保存します
7. コンビニのマルチコピー機で、保存したシートを「写真プリント（L判）」で印刷します（1枚30円ほど）
**便利機能:**
- 「🎯 自動位置合わせ」ボタンで、ずらしてしまってもワンタッチで最適位置に戻せます
- 「↻ 90°回転」で横向きに撮った写真を直せます
- 「明るさ」スライダーで顔写りを調整できます
- 「切り取り線」チェックで、シートにハサミ用のガイド線を入れられます
- カスタムサイズ（mm指定）で、指定された特殊なサイズにも対応できます
**注意・コツ:**
- 写真はこの端末の中だけで処理され、どこにも送信されません
- 保存されるのは300dpiの実寸JPEGです。コンビニ印刷では「L判」を選べばそのままのサイズで印刷されます
- やり直したいときは「別の写真にする」ボタンで最初から選び直せます

## 顔モザイク
**ひとこと:** 写真の顔を自動で見つけてモザイクをかけ、学級だよりやSNS掲載前のプライバシー保護ができます。
**使い方:**
1. 「写真をここにドロップ」の枠に写真を入れるか、「写真を選ぶ」ボタンで選びます（複数枚まとめてOK。JPEG / PNG / WebP）
2. 読み込むと顔が自動検出され、モザイクがかかります
3. 仕上がりを直したい写真をタップして編集画面を開きます（「タップで編集」と表示）
4. 検出漏れの顔は画像をタップして手動で追加、間違って検出された枠はタップして選択し「🗑 選択を削除」で消します
5. 「加工」で「モザイク」「ぼかし」「黒塗り」「😊スタンプ」から選び、「形」（四角/丸）や「強さ」「範囲」のスライダーを調整します
6. 「✓ 完了」で編集を閉じ、「💾 すべて保存」でモザイク済みの写真を保存します
**便利機能:**
- 「感度」を「高（多めに検出）」「標準」「低（確実なものだけ）」から選び、「🔍 再検出」で検出をやり直せます
- 「↩ 戻す」で直前の操作を取り消せます。「全解除」でその写真のモザイクを全部外せます
- 各写真に「💾 保存」ボタンがあり、1枚だけ保存することもできます
- 「＋ 写真を追加」で後から写真を足せます
**注意・コツ:**
- 写真はこの端末の中だけで処理され、どこにも送信されません
- 保存ファイルは元の名前に「_mosaic」が付きます（元がPNGならPNG、それ以外はJPEGで保存）
- 「すべて保存」は1枚ずつ順にダウンロードされます。ブラウザが「複数ファイルのダウンロードを許可しますか」と聞いてきたら許可してください
