## PDFツール
**ひとこと:** 複数のPDFや画像をまとめて、並べ替え・回転・削除・書き込み・軽量化までできる、PDFの万能ツールです。
**使い方:**
1. 画面に PDF や画像をドラッグ&ドロップするか、「＋ PDFを追加」を押してファイルを選びます（複数可。PNG/JPEG/WebP は1枚1ページのPDFになります）
2. ページのサムネイルをドラッグして順番を並べ替えます。ページをクリックすると選択できます
3. 選択したページは「⟲ 左回転」「⟳ 右回転」「選択ページを削除」で整えます
4. ページをダブルクリックすると編集画面が開き、「あ テキスト追加」「▉ 白塗り(修正)」「🖼 画像・印鑑」で書き込めます。終わったら「完了」を押します
5. 必要なら「ページ番号・ヘッダー」を押して、「ページ番号を付ける」や「ヘッダー(上部の文字)を付ける」にチェックを入れ「OK」を押します
6. 「💾 保存(結合して保存)」を押すと、今の並び順どおりの1つのPDFが保存されます
**便利機能:**
- 「🔃 向きの自動修正」…文字の向きから逆さま・横向きのページを検出して自動で直します
- 「選択ページを別PDFに保存(分離)」「1ページずつ分割保存」…必要なページだけ取り出せます
- 「🖼 画像で保存」…ページをPNG/JPEGに変換。解像度は「150dpi(画面用)」「200dpi(標準)」「300dpi(印刷用)」から選べます
- 「🪶 軽量化して保存」…画質を「きれい(150dpi)」「標準(110dpi・メール添付向き)」「最小(90dpi)」から選んでファイルを小さくできます
- 「全選択 / 解除」…全ページをまとめて選択・解除できます
**注意・コツ:**
- 軽量化すると全ページが画像に変換し直されるため、文字のコピー・検索はできなくなります（編集内容・ページ番号・ヘッダーはそのまま焼き込まれます）
- ページ番号・ヘッダーの設定は「保存時に全ページへ適用」されます。設定中はボタンに「●設定中」の印が付きます
- やり直したいときは「すべてクリア」で最初からやり直せます（元のファイルは消えません）

## プリントスキャナー
**ひとこと:** 書類や板書を撮った写真を、傾き補正＋影とりできれいなスキャン風に仕上げ、まとめて1つのPDFにできます。
**使い方:**
1. 書類・板書・掲示物を撮った写真を画面にドロップするか、「🖼️ 写真を選ぶ」または「📷 カメラで撮る」を押します（複数枚OK）
2. 四隅が自動で検出され、まっすぐ・明るく補正されます
3. 仕上がりを直したいページはサムネイルをタップし、「① 範囲」タブで四隅をドラッグして紙のフチに合わせます
4. 「② 仕上がり」タブで「元のまま」「カラー」「グレー」「白黒」から仕上がりを選び、必要なら「⟲ 回転」「⟳ 回転」で向きを直します
5. 「✓ 決定」を押して一覧に戻ります
6. 用紙を「A4(自動で縦横)」か「画像サイズのまま」から選び、ファイル名を入力して「📄 PDFで保存」を押します
**便利機能:**
- 「🔍 自動検出」…紙の四隅をもう一度自動で探します。「⛶ 全範囲」で写真全体を使うこともできます
- 「＋ 写真を追加」…あとから写真を足して複数ページのPDFにできます
- 四隅の調整中はルーペ（拡大表示）が出るので、細かい位置合わせがしやすくなっています
**注意・コツ:**
- 処理はすべてブラウザの中だけで行われ、写真が端末の外に送信されることはありません
- 「全て削除」を押すと読み込んだページが全部消えるので注意してください

## 差し込み印刷
**ひとこと:** Excelの名簿を貼り付けるだけで、賞状・はがき宛名・カードに一人ずつ名前などを差し込んで全員分印刷できます。
**使い方:**
1. 「① 名簿データ」の欄に、Excelからコピーした名簿をそのまま貼り付けます（1行目は見出し）。「1行目を見出しにする」のチェックを確認します
2. 「② 用紙とひな形」で用紙（「A4 たて」「A4 よこ」「B5 たて」「はがき たて」）を選びます。「🏆 賞状のひな形」「📮 はがき宛名」を押すと、ひな形が入ります
3. 必要なら「🖼️ 背景画像(賞状の台紙など)」を押して台紙の画像を設定します
4. 「③ テキスト」で「＋ テキストを追加」を押すか、プレビューの文字をクリックして編集します。文中の {見出し名} がその人のデータに置き換わります
5. 文字サイズ・書体（「ゴシック」「明朝」「教科書体」）・そろえ・色・「太字」「縦書き」などを整えます
6. 「← 前の人」「次の人 →」で一人ずつプレビューを確認します
7. 「🖨️ 全員分を印刷」を押して印刷します。一部だけ印刷したいときは「印刷範囲」に「〜件目」を入力します
**便利機能:**
- プレビュー上でテキストをドラッグ移動でき、選択中は矢印キーで1mm（Shiftキーで0.1mm）ずつ動かせます
- テキストの「複製」ボタンで同じ設定の文字枠をすぐ増やせます
- 「背景も印刷する」のチェックを外すと、印刷済みの賞状用紙に文字だけを乗せて印刷できます
- 位置は「横位置 mm」「縦位置 mm」で数値でも指定できるので、市販用紙への位置合わせに便利です
**注意・コツ:**
- 名簿データは端末の外に出ません（貼り付けたデータはこの端末内だけで処理されます）
- 印刷はブラウザの印刷画面から行われます。用紙サイズは自動設定（余白0）されるので、印刷画面の用紙サイズがアプリの設定と合っているか確認してください

## テキスト整形
**ひとこと:** PDFから貼り付けたときの変な改行、全角半角のばらつき、名簿の区切りなどを、貼り付けるだけで一瞬で整えます。
**使い方:**
1. 「入力」欄に文章や名簿を貼り付けます（「貼り付け」ボタンでも入れられます）
2. まずは上のワンタッチボタン「📄 PDFの貼り付けを直す」「👥 名簿を1行1人に」「📊 Excelへ(改行→タブ)」「🔢 数字・英字を半角に」を試します。結果は右側（スマホは下）に即時表示されます
3. 細かく直したいときは「🧹 改行・空白の掃除」「🔡 全角 ⇄ 半角」「🔤 かな・機種依存文字」「📑 行の並べ替え・整理」「🔢 行頭の番号・記号」「🔁 置換」の各設定を変えます
4. 仕上がったら「📋 コピー」を押して、WordやExcelに貼り付けます
5. 設定をやり直したいときは「↺ 全部リセット」を押します
**便利機能:**
- 「文字数上限」に数字（例:300）を入れると、所見など字数制限のある原稿で超えた分が赤く表示されます。文字数・行数・400字詰め換算も常に表示されます
- 「機種依存文字を変換」にチェックすると ①→(1)、㈱→(株) などの安全な表記に置き換わります。見つかった機種依存文字は結果の下に一覧表示され、結果の中でも黄色くマークされます
- 「⬅ 入力にする」…結果を入力欄に移して、続けて別の整形をかけられます
- 並べ替え（昇順・降順・逆順・シャッフル）や「重複する行を削除」で名簿の整理ができます
- 置換は上から順に3つまで設定でき、「正規表現」にも対応しています
**注意・コツ:**
- 文字は端末の外に出ません（すべてこの端末内で処理されます）
- 人名の異体字（髙・﨑 など）は自動では変換されないので、必要なら手で直してください

## 面付け・小冊子
**ひとこと:** PDFを「両面印刷して半分に折るだけで中綴じ冊子になる」ページ順に並べ替えたり、1枚の用紙に2面・4面・8面を割り付けたPDFを作れます。
**使い方:**
1. PDF や画像（JPEG/PNG/WebP）を画面にドロップするか、「ファイルを選ぶ」を押します（複数まとめてOK・ページ順に連結されます）
2. 「📕 小冊子(中綴じ)」か「🔢 面付け(N-up)」のタブを選びます
3. 小冊子なら、用紙（「A4(仕上がりA5)」「A3(仕上がりA4)」「B4(仕上がりB5)」「B5(仕上がりB6)」）と綴じ方向（「左綴じ(横書き)」「右綴じ(縦書き・国語)」）を選びます
4. 面付けなら、用紙・面数（「2面」「4面」「8面」）・並べ方（「同じページを並べる(裁断用)」「ページ順に割り付け(節約印刷)」）を選びます
5. プレビュー（印刷される用紙そのまま）で仕上がりを確認します
6. 「💾 PDFを保存」を押し、保存されたPDFを印刷します
**便利機能:**
- 「切り取り線を入れる」…面付け（裁断用）のとき、切る位置の線を自動で入れられます
- 「同じページを並べる(裁断用)」…小テストや連絡カードをA4に2枚・4枚並べて、裁断して配れます
- 「ページ順に割り付け(節約印刷)」…配布資料の用紙節約に使えます
- 「別のファイルにする」でファイルをすぐ差し替えられます
**注意・コツ:**
- ファイルはこの端末の中だけで処理され、どこにも送信されません
- 小冊子の印刷のコツ:「両面印刷(短辺とじ)」で印刷し、印刷順のまま重ねて半分に折り、折り目を綴じれば完成です
- 裏面が上下逆さまに出るプリンタでは、「長辺とじ」に変えるか「裏面を180°回転」をオンにしてください
