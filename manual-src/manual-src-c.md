## 一括リネーム
**ひとこと:** フォルダ内のファイル名を、連番・日付・文字の置き換えルールでまとめて変更できます（実行前に全件プレビューで確認できます）。
**使い方:**
1. 「📂 フォルダを開く」を押してフォルダを選びます（アクセス許可の確認が出たら許可）。フォルダを直接変更したくない場合は「🖼️ ファイルを選ぶ（ZIP保存）」やドラッグ＆ドロップでもOK
2. 「新しい名前」欄でルールを決めます。難しければ「よく使う形」の「そのまま」「名前_連番」「連番_名前」「日付_名前」「写真_連番」ボタンを押すだけでOK（{name}=元の名前、{num}=連番、{date}=日付。拡張子は自動で残ります）
3. 特定の文字を消したい・変えたいときは「置き換え」に「探す文字（例：IMG_）」と「置き換え後（空欄で削除）」を入力します
4. 必要に応じて「連番」の開始・桁数、「日付」（ファイルの更新日／今日）、「並び順」、「絞り込み」（例：.jpg）を調整します
5. 「📋 プレビュー」で変更後の名前を全件確認します（重複や使えない文字があると⚠で教えてくれます）
6. 「📂 リネーム実行」（フォルダモード）または「📦 ZIPで保存」（ファイル選択モード）を押します
7. 失敗したと思ったら「↩ 元に戻す」でリネーム前の名前に戻せます
**便利機能:**
- 実行前にプレビューで全件確認でき、名前の重複・使えない文字は自動でチェックして実行をブロックします
- 「↩ 元に戻す」でリネームをまとめて取り消しできます
- 「絞り込み」で「.jpg」など特定のファイルだけを対象にできます
- 並び順を「更新日が古い順」などに変えると、撮影順の連番付けができます
- 「↻ 読み直す」でフォルダの中身を再読み込みできます
**注意・コツ:**
- 「フォルダを開く」（直接リネーム）はChrome・Edgeでのみ使えます。他のブラウザではZIP保存モードのみです
- 処理はすべてブラウザの中だけで行われ、ファイルが端末の外に送信されることはありません
- ZIP保存モードは元ファイルを変更せず、「リネーム済み_日付.zip」としてコピーをダウンロードします

## QRコード工房
**ひとこと:** QRコードを「つくる」「まとめて作る」「よみとる」が1つでできます（データは端末の外に出ません）。
**使い方:**
1. 「つくる」タブで種類を選びます：「テキスト・URL」「Wi-Fi」「メール」「電話」
2. 内容を入力すると、その場でQRコードのプレビューが更新されます
3. 「QRの下に入れる文字（任意）」に「例：学級アンケートはこちら」のような説明を入れられます
4. 必要なら「読み取りやすさ（誤り訂正）」「保存サイズ px」「QRの色」「背景の色」を調整します
5. 「PNG保存」「SVG保存」「コピー」で保存、または「A4に大きく1面／4面／9面／16面」を選んで「🖨️ 印刷」
6. たくさん作るときは「まとめて作る」タブに1行1つずつ貼り付け→「まとめて生成」→「ZIPで全部保存」または列数（印刷 2〜5列）と「切り取り線」を選んで「🖨️ 印刷」
7. 読み取りたいときは「よみとる」タブで「📷 カメラ起動」、または画像をドロップ／Ctrl+Vで貼り付け。結果から「コピー」「開く」「この内容でQRを作る」が使えます
**便利機能:**
- Wi-Fi用QR：SSIDとパスワードを入れるだけで、スマホのカメラで読むと接続できるQRになります
- まとめて作るとき、「1班（タブまたはカンマ）URL」の形式で貼ればラベル付きQRになります（「先頭列をラベルにする」）
- QRの色が薄い・背景と逆のときは「⚠️ 読み取れない機種があります」と警告が出ます
- 入力内容は自動でブラウザに記憶され、次回開いたときに復元されます
- Wi-FiのQRを読み取ると、ネットワーク名・パスワードを表に整理して表示し、パスワードだけをコピーできます
**注意・コツ:**
- 生成も読み取りもすべて端末内で処理され、データが外部に送信されることはありません
- カメラ読み取りは公開ページ（HTTPS）で開いたときだけ使えます
- まとめて生成は一度に400件までです

## オーディオスタジオ
**ひとこと:** ブラウザだけで音声のカット・無音詰め・速度/ピッチ変更・ノイズ除去・カラオケ化・AI楽器分離までできる音声編集ツールです。
**使い方:**
1. 音声ファイルを画面にドロップするか「📂 開く」で選びます（MP3 / WAV / M4A / OGG など）。「⏺ 録音」でマイクから録音して始めることもできます
2. 波形をドラッグで範囲選択、クリックで再生位置を移動。「▶」で再生、「🔁 ループ」で選択範囲を繰り返し再生します
3. 上のタブから機能を選びます：「✂️ 編集」「🤫 無音カット」「⏱️ 速度・ピッチ」「🔊 音量」「✨ クリア・EQ」「🎤 ボーカル」「🥁 楽器分離」「🤖 AI分離」
4. 例1（切り出し）：範囲を選んで「✂️ 選択範囲だけ残す」または「🗑️ 選択範囲を削除」
5. 例2（間詰め）：「🔍 無音を検出（プレビュー）」→オレンジ表示を確認→「✂️ 無音をカットする」
6. 例3（聞き取り教材）：「⏱️ 速度・ピッチ」でスライダーを動かして「適用」、または「✨ クリア・EQ」の「🗣️ 声を聞き取りやすくする」をワンタッチ
7. 失敗しても「↩ 元に戻す」「↪ やり直す」でいつでも取り消せます
8. 仕上がったら「💾 WAV」「💾 MP3」で保存します。分離結果は各パートごとに「▶」「💾 WAV」「💾 MP3」「✏️ エディタで開く」が使えます
**便利機能:**
- 「💾 選択範囲だけWAV書き出し」で必要な部分だけ保存できます
- ノイズ除去は「1️⃣ ノイズだけの区間を選択して学習」してから実行すると精度が上がります
- 速度・ピッチ・音量などは範囲選択中ならその範囲だけに適用されます
- 「🥁 楽器分離」はネット接続不要・数秒〜数十秒で、ドラムとメロディの2つに分けられます
- 「🤖 AI分離」はボーカル/ドラム/ベース/その他の4パートに本格分離できます
**注意・コツ:**
- ファイルはPCの外に送信されません（AI分離のモデル取得時とMP3エンコーダの読み込み時のみ通信が必要です）
- AI分離は初回のみ数十MBのモデルをダウンロードし、曲の長さによって数分かかります。10分を超える音源は分割してから実行してください（楽器分離は12分まで）
- 「🎤 ボーカルカット」はステレオ音源専用です。モノラル音源には使えません（その場合はAI分離へ）

## 大型タイマー
**ひとこと:** 教室のスクリーンやプロジェクタに大きく映せる、円形メーター付きのカウントダウンタイマー＆ストップウォッチです。
**使い方:**
1. 「カウントダウン」か「ストップウォッチ」を選びます
2. カウントダウンなら「1分」〜「45分」のプリセットボタンを押すか、「分」「秒」の欄に直接入力します
3. 「▶ スタート」で開始します（もう一度押すと「❚❚ 一時停止」）
4. 「↺ リセット」で最初からやり直せます
5. 発表会や授業では「⛶ 全画面」にして「⌃ パネル」で操作パネルを隠すとすっきり大きく映せます
6. 「🔔 音 ON」を押すと終了チャイムのオン/オフを切り替えられます
**便利機能:**
- キーボード操作：Space（スタート/一時停止）、R（リセット）、F（全画面）、H（パネル表示切替）、1〜9（その分数をセット）
- 残り1分で黄色、残り10秒で赤に変わり、終了すると画面が点滅してチャイムが鳴ります（残り3・2・1秒には刻み音）
- 残り1分未満は0.1秒単位の表示になり緊張感が伝わります
- タイマー動作中は画面が自動スリープしにくくなります（対応ブラウザ）
**注意・コツ:**
- 音はブラウザの仕様上、一度画面を操作（スタート等）してからでないと鳴らないことがあります
- ブラウザのタブのタイトルにも残り時間が表示されるので、別タブ作業中でも確認できます

## ランダム指名ルーレット
**ひとこと:** クラスの名簿から1人を、スロットマシン／ルーレットの演出つきでランダムに指名できます。
**使い方:**
1. 「👥 名簿」を押し、1行に1人ずつ名前を貼り付けます（Excelの列コピーそのままでOK。行頭の出席番号「1.」「01 」などは自動で外れます）
2. 「✓ この名簿を使う」を押します
3. 「🎯 スタート」で抽選開始（Spaceキーや画面クリックでもOK）
4. 当選者が画面いっぱいに表示され、紙吹雪とファンファーレでお祝いされます
5. 「✋ 選ばれた人は除外」をオンにしておくと、同じ人が2回選ばれません。全員選ばれたら「↺ リセット」でもう一周
6. 名簿画面で「クラス名（例：2年3組）」を入れて「💾 保存」すると、次回から「📚 保存したクラス…」で呼び出せます
**便利機能:**
- 「🎰 スロット」ボタンで演出を「🎡 ルーレット」と切り替えられます
- 画面下部に選ばれた人の履歴が番号付きで並ぶので、指名順の記録になります
- 複数クラスの名簿を保存でき、不要になったら「🗑」で削除できます
- 「🔊 音」で効果音のオン/オフ、「⌃ パネル」で操作ボタンを隠して大きく映せます
**注意・コツ:**
- 名簿・履歴・設定はブラウザ内に保存されます。同じPC・同じブラウザで開いたときだけ引き継がれます
- 名簿の内容を変更して「この名簿を使う」を押すと、抽選履歴はリセットされます
- 「リセット」ボタンは履歴（選ばれた人の記録）を消すもので、名簿自体は消えません
